Scale trusted conversations, not replace them

Needs attention → Schedule → Conversation → Choose together → Checkout → Follow up → Outcomes.

The local console now connects an internal appointment or walk-in to offered books, an explicit choice, an atomic loan link, and book-specific feedback. The existing student workspace stays intact.

Attention queue → Internal appointment → Conversation
                                           ↓
                            Available candidates → Student choice
                                                        ↓
Activity + reported outcomes ← Book feedback ← Linked checkout

Choosing does not reserve copies. Checkout revalidates inventory. Only an explicit action completes the conversation; borrowing is not finishing or enjoyment.

Linked evidence and an honest stopping point

Catalog + circulation → Retrieve → Policy → Optional explanation
                                        ↓
Calendar → Session coordinator → Offer → Choice → Loan
                  ↓                (one inventory/link transaction)
          Completed interaction → Structured feedback
                  ↓
          Pure metrics → Counts + supporting tables
  • Built: My day, available-slot booking and rescheduling, reserved follow-up conversations, linked checkouts, structured book feedback, and session activity tables.
  • Outcomes → Student trends: borrowing totals, English-grade distributions and compatible reading observations roll up from the same student records, with source-labelled drill-downs.
  • Exact denominators: distinct students, completed conversations, mature 14-day choice conversion, known reading/enjoyment responses and due follow-up coverage.
  • Outcomes → Reading changes: descriptive served-cohort pairs from isolated fictional historical contacts, with sample sizes, exclusions and supporting observations—not a causal staff score.
  • Deferred: historical recommendation/feedback funnels, calendar notifications, production permissions and ILS writeback.

A new conversation has no months-later outcomes. Pending observation windows and missing responses remain visible. Existing academic scenarios are isolated illustrations, not evidence of staff effectiveness.

SignalWhenHonesty rule

Bounded LLM — optional drafts

  • Default: TemplateExplainer. No “funny enough to finish.”
  • On: OpenAI-compatible POST to $LLM_BASE/v1/chat/completions. Timeout, size cap, book_id keys.
  • Invented IDs dropped. Missing items filled from template. Ranking and scores unchanged (mock success and mock failure in tests).
  • Live Axon was not called from this worktree. Offline demo does not depend on it.

Failure demo: set SHELFMATE_LLM=on with no LLM_BASE, or stop the router. Console shows explain_mode=fallback. Recs identical.

Eval — what it proves and what it does not

Executable goldens in testdata/golden/cases.json (notes field; no show field). go test ./..., race, and vet passed on this worktree.

  • Proves: closed catalog, B-008 never spoken, Mateo includes Cat Kid, Priya page cap, Olivia returns ≥3, payload has no first names.
  • Does not prove: more reading, better grades, FERPA certification, or that checkout equals reading.

Checkout is not completion or enjoyment. Session Outcomes now reports explicitly linked choice-to-checkout conversion within 14 days, using only choices with a full observation window; new choices remain pending. Synthetic grades are not caused by a title.

Privacy controls vs later production work

Implemented now

  • No last names / DOB in extract
  • Model payload allowlist + tests
  • Audit without raw query or names
  • Localhost bind
  • LLM off by default

Not this PoC

  • Staff SSO
  • Destiny nightly export
  • Written privacy-officer approval
  • Retention/deletion of audit files
  • Network egress policy

Adoption, support, approval gates

  • Adoption: Elena and Tom on the Maple Street desk. Teachers do not get a student-facing link.
  • Support: local binary + JSON extract. When the model is down, retrieve still works.
  • Gates: (1) privacy officer written yes before LLM on, (2) catalog-closed eval green, (3) Bad Guys fixture never spoken, (4) no student UI.

Out of scope: student accounts, full-text generation, Battle of the Books training, replacing Destiny, patent claims from unrelated work.
