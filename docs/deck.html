Thesis (non-negotiable)

  1. Human in the loop. Librarian speaks. No student login, no public feed.
  2. Retrieve first. Item-item CF (circulation) + catalog TF-IDF. Every recommended book_id ∈ catalog.json.
  3. LLM last and optional. Talking points only. Invented IDs dropped. Kill switch: ranking identical.
  4. Availability is a feature. copies_available == 0 is never spoken (B-008 The Bad Guys).
  5. Privacy first. Model gets student_id + candidate metadata. Names stay on the desk.
  6. Handoff, not slideware. Binary + JSON contract + eval goldens + Graft map.

Inputs librarians offered: borrow history + electronic card catalog. Grades/counselor context are optional, approval-gated extensions — not required for the core path.

Recommend path (hot path)

  1. Desk lookup → httpapi → engine on immutable session snapshot.
  2. retrieve.Hybrid — item-item cosine weight 0.55 when history ≥ 2 unique titles; TF-IDF content 0.45 (or 1.0 if sparse). Query vector ≠ history vector. Cluster/series bonus additive (not “next volume”).
  3. Zero history + no query hit → unique-borrower popularity, book_id tie-break, labeled fallback.
  4. policy.Filter re-reads store membership: unknown IDs out; copies_available == 0 out; grade/stretch; never re-loan; under 150 = <150 pages (short ≈ 180).
  5. explain drafts talking points for already-ranked IDs. Ranking cannot change.
  6. Optional CLI audit JSONL (opaque IDs, dropped reasons, explain mode). Write failures surface.

Graft: hybrid-recommender → policy-eligibility-gate → recommendation-engine → ranking-invariant-llm-enrichment.

Hard policy (store re-read, not candidate trust)

  • Recommend only book_id present in store.
  • Drop out-of-copies titles before they become spoken recs.
  • Stretch = librarian checkbox (grade_min ≤ grade+1 ∧ grade_max ≥ grade) — does not invent ability or change CF weights.
  • Conservative: never re-recommend any previously borrowed title.

LLM + privacy boundary

Stays on the desk

  • First name + last initial
  • Raw NL query / anecdotes
  • Blurbs (fixture may contain a name)
  • Full student record / lexile
  • Synthetic academics
  • Credentials / raw model bodies

If SHELFMATE_LLM=on

  • student_id only
  • Candidate book_id + catalog fields
  • Retrieve reasons, stretch / page flags
  • Allowlisted themes only
  • Unknown emitted IDs dropped
  • Scores unchanged on success or failure

Default off → TemplateExplainer. On → Anthropic Messages (ANTHROPIC_BASE_URL) or OpenAI-compatible (LLM_BASE + /v1/chat/completions). Default model auto:medium. Timeout + size cap. Proven with engine mocks.

Graft: privacy-minimization, explainer, ranking-invariant-llm-enrichment. See privacy.md.

Serve path: session, engagement, metrics

  • session.Service — clone-on-write books + circulation; monotonic inventory revision; restart = reset. Recs run outside the writer lock on an immutable snapshot; checkout rechecks copies under lock.
  • Engagement — appointments, conversations, choices, atomic linked checkout, structured book feedback; separate engagement revision + RetryID receipts. Choice alone does not consume inventory.
  • Calendar — district IANA TZ, school-year bounds, DST-safe whole-minute slots; web/slots.js + server share the same five-minute candidates.
  • Support triage — desk bands from local fixtures; counselor themes do not drive bands; only explicit reading-theme choices affect local search. Not sent to the model.
  • Outcomes — Our work (live) ≠ Student trends (portfolio) ≠ Reading changes (historical paired fixture). Descriptive only — no causal staff scoreboard.
  • Academics scenarios — isolated from retrieve, ranking, support, explainer payloads, and audit.

Graft: session-service, engagement-scheduling, support-triage, district-metrics, honest-missingness, academics-catalog.

Eval — what green proves (and does not)

go test ./... · focused: go test ./internal/eval ./internal/retrieve ./internal/policy ./internal/explain

Proves

  • Every rec id ∈ catalog
  • Mateo: Cat Kid / Investigators path; B-008 never spoken
  • Priya: sparse CF + page cap; Olivia: ≥3 labeled fallback
  • Payload has no first names
  • LLM mock success/failure leave ranking identical

Does not prove

  • More reading or better grades
  • FERPA certification
  • Checkout = finished / enjoyed
  • Staff effectiveness from historical pairs
  • Production auth / ILS writeback

Goldens: testdata/golden/cases.json. Graft: closed-world-recommendations, domain-vocabulary.
