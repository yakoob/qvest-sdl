ShelfMate: retrieve → policy → optional explain → human approve

Librarian-in-the-loop next-book assistant. Single Go binary. Closed-world catalog. LLM off by default and downstream of ranking. Not a student app.

Thesis (non-negotiable)

  1. Human in the loop. Librarian speaks. No student login, no public feed.
  2. Retrieve first. Item-item CF from circulation + catalog TF-IDF. Every recommended book_id ∈ catalog.json.
  3. LLM last and optional. Talking points only. Invented IDs dropped. Kill switch: ranking unchanged.
  4. Availability is a feature. copies_available == 0 is never a spoken rec (fixture: B-008 The Bad Guys).
  5. Privacy first. Model payloads: student_id + candidate metadata. Names stay on the desk.
  6. Handoff, not slideware. Binary + JSON contract + eval goldens + Graft map.

Product goal for the firm: scale librarian impact without scaling headcount, while reducing desk workload. Architecture must make that believable under review.

Request sequence

  1. Lookup student on desk console.
  2. Hybrid.Recommend — item-item cosine (weight 0.55 when history ≥ 2) + TF-IDF content (0.45, or 1.0 if sparse). Query vector ≠ history vector. Cluster/series bonus additive.
  3. Zero history / no query hit → unique-borrower popularity, book_id tie-break, labeled fallback.
  4. policy.Filter — unknown IDs out; copies_available == 0 out; grade/stretch band; never re-loan; under 150 = <150 pages.
  5. Explainer drafts talking points for already-ranked IDs. Ranking frozen.
  6. Audit append (opaque IDs, dropped reasons, explain mode). Write errors surface.
  7. Optional demo checkout under session lock; recommendation runs on immutable snapshot outside the writer lock.

Circulation CF onlyEmpty for Priya (1 checkout) and Olivia (0).
TF-IDF onlyMisses Mateo’s graphic neighborhood that co-checkout cosine catches.
LLM as generatorInvented titles, no shelf truth, FERPA surface area.
Hybrid → policy → optional talkClosed catalog, availability as a feature, model killable.

Hard policy

  • Recommend only book_id present in store (re-read membership; do not trust candidate structs).
  • Drop copies_available == 0.
  • Grade: grade_min ≤ grade ≤ grade_max; stretch: grade_min ≤ grade+1 and grade_max ≥ grade.
  • Conservative: never re-recommend any previously borrowed title.

LLM boundary

Stays on the desk

  • First name + last initial
  • Raw NL query / anecdotes
  • Blurbs (fixture risk)
  • Full student record / lexile
  • Synthetic academics
  • Credentials / model bodies

If LLM is on (optional)

  • student_id only
  • Candidate book_id + catalog fields
  • Retrieve reasons, stretch / page flags
  • Allowlisted themes only
  • No names, no raw query, no blurbs
  • Unknown emitted IDs dropped

SHELFMATE_LLM=off (default) → TemplateExplainer. On → Anthropic Messages or OpenAI-compatible chat completions. Timeout + size cap. Success or failure: scores unchanged (proven in internal/engine mocks).

Graft: privacy-minimized-payloads, explain-plane, llm-never-changes-ranking. Tests: TestPayloadPrivacy.

Session, engagement, metrics

  • Process-local session.Service — clone-on-write books + circulation; monotonic inventory revision; restart = reset.
  • Engagement coordinator — appointments, conversations, choices, linked checkout (atomic with inventory), structured book feedback; separate engagement revision + RetryID receipts.
  • Calendar — district timezone, school-year bounds, DST-safe whole-minute slots; shared web/slots.js + server validation.
  • Outcomes — Our work (live session) ≠ Student trends (portfolio) ≠ Reading changes (historical paired fixture). Descriptive, not causal staff scores.
  • Academics scenarios — isolated from retrieve, ranking, support bands, explainer payloads, and audit.

Graft: in-memory-session-service, engagement-session-calendar-and-http, historical-vs-live-session-isolation, descriptive-evidence-not-causal-attribution, observational-metrics-invariants.

Eval — what green means

go test ./internal/eval ./internal/retrieve ./internal/policy ./internal/explain (and go test ./... for full suite).

  • Closed catalog: every rec id ∈ catalog
  • Mateo top-5 includes Cat Kid (B-007) or Investigators path; B-008 never spoken
  • Priya page-cap + sparse-history path; Olivia returns ≥3 labeled fallback
  • Model payload has no first names
  • LLM mock success and mock failure leave ranking identical

Does not prove: more reading, better grades, FERPA certification, or that checkout equals enjoyment.
